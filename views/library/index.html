HOW IT WORKS

使用说明

  1. 在「曲库检索」搜索歌名、歌手、专辑或 songmid；留空搜索会列出最新入库。
  2. 在左侧曲目列表勾选歌曲，在右侧发送队列勾选目标群，或手动填写 QQ 群号。
  3. 点「发送」，任务在后台执行；「发送任务」可查看每首歌到每个群的结果。
  4. 首次使用先配置 API 地址和 Token；未配置 Token 时不会请求 API 本地曲库。
  5. 页面只提交曲库 ID 和群号，带签名的音频地址由服务端重新获取，不会回传到浏览器。
