# 外部平台链接解析

机器人消息中出现以下分享链接时会自动交给本插件：

- Spotify 单曲、专辑、歌单
- Apple Music 单曲、专辑
- B站视频、BV/AV 号或 `b23.tv` 短链

单曲直接调用 API 的本地优先匹配并发送。专辑、歌单和B站视频把可播放曲目写入当前点歌会话，随后可用 `#qqm听序号` 选择。Spotify/Apple 只提供曲目索引，不会把它们的受保护音频当成普通文件；实际文件保留本地或其他平台的来源、版本与实际音质。

外部批量链接单次最多处理 30 首。未匹配条目不会伪造音源；部分匹配时会显示命中数量，截断也会明确提示。Spotify 需要先在 Token 管理器配置应用凭据；B站使用现有官方账号槽位。关闭 `resolveExternal` 可恢复只解析 QQ 音乐链接。

入口测试不访问真实平台：`node scripts/test-external-resolve.mjs`。
