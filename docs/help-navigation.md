## 每日计划简写（仅主人）

`#qqm刷歌每天 周杰伦 确认`

默认 QQ、歌手、每轮 60 分钟、每天 00:05、持续执行；参数提交到 API 后保存，插件不另起后台定时器。

`#qqm刷歌每天 专辑 叶惠美 20次 确认`：专辑只执行 20 轮。

`#qqm刷歌每天 歌曲 晴天 30分 08:30 确认`：每天 08:30，单轮 30 分钟。

可选参数依次放在目标后：`30分 20次 08:30`，未写的使用默认值。旧的 `#qqm刷歌计划 QQ 歌手 周杰伦 60 一直 00:05 确认` 继续兼容。

已保存的计划不用重新填写：

- `#qqm刷歌计划` 或 `#qqm刷歌计划列表`：查看本人计划及 ID。
- `#qqm刷歌暂停 确认`：暂停唯一计划。
- `#qqm刷歌继续 确认`：恢复唯一计划。
- `#qqm刷歌立即 确认`：立即执行唯一计划。
- `#qqm刷歌删除 确认`：删除唯一计划。

有多个计划时加完整目标名或计划 ID，例如 `#qqm刷歌暂停 周杰伦 确认`。同名目标有多个计划时必须用 ID。省略目标不会批量操作。

计划暂停用于后续调度；已运行的单次任务通过 `#qqm刷歌停止 确认` 停止。已接收量和平台统计增量分开显示，真实账号入账未完成验收。

## Token 绑定槽与发送者 ID 不同

独立 Token 的账号槽是 API 服务端分配的名称，不需要与机器人的发送者 ID 相同。主人使用独立 Token 时，插件先读取 API 的身份元信息，再让搜索、任务、计划与状态全部使用同一个绑定槽；结果会注明使用了 Token 绑定账号。

请同时更新 API 与插件。共享 Token 用于借用别人的播放账号，不支持这些任务；应在 Token 管理器新建独立 Token，并通过它扫码登录自己的账号。主密钥仍按发送者槽位，不自动回落公共账号。

独立 Token 的计划保留访客权限，只能列出和修改自己的计划；Token 停用、删除或改绑后，调度会暂停计划。
