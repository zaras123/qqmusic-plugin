# 2.1.11

Yunzai 与 Karin 分支统一使用 2.1.11。

- 接入平台时长任务的命令、专用帮助和状态卡片；classic、apple、nebula、multi 四套主题均提供卡片。
- 状态展示当前歌曲与歌手，区分请求新增、平台接收和平台统计增量；提供计划列表及控制入口。
- 支持歌曲、专辑、歌手目标以及持续执行或固定轮数；后台任务由配套 API 管理。
- 点歌列表同时显示本地曲库、QQ 官方和已启用的填充渠道；锅巴 / Karin WebUI 可关闭本地曲库优先。
- 精简首页说明，详细内容移至 docs；修正 Karin npm 首页 Logo 地址。

## 更新

Yunzai：更新 main 分支。Karin：更新 npm 包 karin-plugin-qqmusic 或 karin 分支。
同时更新配套 qqmusic-api-enhanced；仅更新插件不会添加 API 任务和计划接口。

主人可发送 `#qqm刷歌帮助`、`#qqm刷歌状态`、`#qqm刷歌计划列表`。
任务只使用发送者本人的登录态；真实平台账号是否计入仍需以平台统计验收。
