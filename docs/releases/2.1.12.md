# 2.1.12

- 主帮助改为常用功能与分类入口，新增点歌、发现、平台、登录、解析、订阅、统计、一起听、演出、刷歌、账号和管理帮助卡片。
- 分类卡片按身份过滤，图片渲染失败时回退到同一份文本内容。
- 新增短命令：`#qqm刷歌每天 周杰伦 确认`、`#qqm刷歌暂停 确认`、`#qqm刷歌继续 确认`、`#qqm刷歌立即 确认`、`#qqm刷歌删除 确认`。
- 多个计划同名或省略目标造成歧义时不执行写操作；计划列表显示 ID。
- 修复独立 API Token 绑定槽位与聊天发送者 ID 不同导致刷歌任务被拦截的问题。
- 独立 Token 的搜索、任务、状态和计划统一使用服务端确认的绑定槽；共享 Token 不支持时长任务。
- 计划保留访客权限；Token 停用、删除或改绑后自动暂停，并尝试停止当前任务。
- 四套主题帮助模板支持详情卡片的长命令换行，不截断操作示例。
