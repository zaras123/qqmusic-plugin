# 本地曲库与渠道显示

点歌结果固定按以下顺序组织：

1. 本地音乐库命中。
2. QQ 音乐官方搜索结果。
3. 已启用的第三方填充渠道。

本地优先只改变排序，不会隐藏官方结果或已启用的填充结果。每首歌会显示实际交付渠道，例如：

- `本地库 · 网易云 · FLAC`
- `QQ音乐官方`
- `填充 · 酷我 · 128k`

## 锅巴开关

打开「本地曲库优先」时，搜索、播放链和外部链接解析都会先查本地库。关闭后，插件对 `/search`、`/song/url` 和 `/resolve/*` 统一发送 `local=0`，不会再读取本地文件。

在意本地文件音质时，可以同时设置「最高音质」并关闭「音质自动降级」，强制本地文件必须达到指定档位；也可以直接关闭本地曲库，改走 QQ 官方或第三方渠道。

第三方填充开关独立控制。关闭本地曲库不会关闭 QQ 官方搜索，也不会自动关闭已启用的平台填充。
